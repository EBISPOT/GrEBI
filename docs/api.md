
# API reference

Every endpoint of the GrEBI API, from the OpenAPI description the API itself serves at `/api/v1/openapi.json` (and as YAML at `/api/v1/openapi.yaml`), which any OpenAPI tool can use to generate a client. The worked examples in [Using the GrEBI API](#using-the-grebi-api) show the common calls in context.
